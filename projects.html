Deblurring from a Single Blurry Image using 3D Gaussian Splatting and Event Streams

Developed a framework to reconstruct sharp 3D scenes from just one blurry image, leveraging event streams for motion-aware deblurring. Jointly optimized 3D Gaussians and differentiable SE(3) Bézier trajectories, achieving ~4× faster training and 61% lower GPU memory usage with competitive PSNR across 15+ scenes.

Caster-Aware Model Predictive Control for an Autonomous Mobile Robot

Built during my autonomy internship at Ati Motors. Designed an MPC planner in CasADi that accounts for the robot's caster wheels while planning, and validated it on an Isaac Sim model of the AMR, reducing steering-induced torque by 70%.

Deadlock-Free Multi-Robot Path Planning with Space-Time A*

Course project with Prof. Nirav Patel. Built a cooperative planner on a modified Space-Time A* that detects deadlocks through graph analysis and resolves them with hybrid joint-space replanning. Coordinates 100 robots on a dense 20×20 grid in under a second, staying deadlock-free in edge cases.

Autonomous Navigation for a Model Surface Vessel with EKF and Line-of-Sight Guidance

Course project with Prof. Abhilash S. Fused IMU and UWB measurements in an Extended Kalman Filter for real-time localization and full-state odometry, then built Line-of-Sight guidance with a rudder PID controller that tracks waypoints with under 0.1 m RMS cross-track error.
