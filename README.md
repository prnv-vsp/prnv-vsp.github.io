# Portfolio
Plain HTML/CSS/JS. No build step.
Preview: VS Code "Live Server" (right-click index.html → Open with Live Server) or `python -m http.server 8000`.
Edit: index.html, projects.html, cv.html. Colors/theme: assets/css/style.css (:root variables).
Add: assets/img/profile.jpg, assets/pdf/cv.pdf.
Deploy: push to main; GitHub Settings → Pages → Deploy from branch → main / root. Keep the empty .nojekyll file.
